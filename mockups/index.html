오늘의 운세 화면 시안 다섯 가지예요. 같은 테마 안에서 입력 방식, 결과 표현, 움직임을 서로 다르게 잡았어요. 줄을 누르면 입력부터, 결과 버튼을 누르면 결과 화면이 바로 열려요.

05 SAMPLES
  1. 01

    문장

    빈칸을 채워 한 문장을 완성하면 답도 한 문장으로 와요. 밑줄 친 말을 누르면 각주가 열려요. 입력 · 문장 속 빈칸  /  결과 · 각주가 달린 문단

    결과 →
  2. 02

    눈금

    눈금자를 끌어 값을 맞출수록 오차 범위가 좁아지고, 결과에서는 하루의 흐름을 커서로 훑어봐요. 입력 · 끌어서 맞추는 눈금자  /  결과 · 계단형 하루 그래프

    결과 →
  3. 03

    구궁

    숫자판으로 누를 때마다 아홉 칸이 하나씩 밝혀지고, 결과판의 칸을 누르면 그 줄과 칸이 펼쳐져요. 입력 · 숫자판  /  결과 · 3×3 운세판

    결과 →
  4. 04

    카드

    한 장에 한 질문씩 답할수록 카드 문양이 선명해지고, 뽑은 카드는 밀어서 넘기고 눌러서 뒤집어요. 입력 · 한 장씩 넘기는 질문  /  결과 · 넘기고 뒤집는 카드 더미

    결과 →
  5. 05

    보드

    한 줄로 적으면 바로 읽어 플랩에 띄우고, 결과는 시간대를 바꿀 때마다 다시 뒤집히는 안내판이에요. 입력 · 한 줄 자유 입력  /  결과 · 플랩 안내판
